feat(pi-tiered-subagents): route both launch doors through one preparation authority

A request used to be prepared differently depending on which door it
arrived through. The tool door selected the definition through
registry.select and resolved with the live operator settings; the
service door looked the definition up with registry.find and, when the
id was not known, silently substituted a synthetic shipped default, and
it never saw the operator's turn defaults at all. Equivalent requests
could therefore resolve differently.

Now there is one path. A session-scoped Subagents seam owns the call
sequence: capture the session owner, prepare through LaunchPreparer,
capture the parent snapshot and session identity, then accept into the
manager. Both doors translate their own vocabulary into one request and
consume the same prepared value; neither selects definitions, reads
model facts, or assembles manager options on its own.

LaunchPreparer is the one selection authority: it refreshes the file
layers, selects the definition (unknown and disabled are rejections
with distinct reasons, never a substitute), validates the caller's
thinking level once, and captures the operator turn defaults and parent
model facts with the request. The selected definition is copied so a
later registry edit cannot widen a prepared launch's capabilities.

The prepared definition travels with the launch to execution.
SubagentManager accepts a definition from the door when one is offered
(internal callers without one keep the manager's checked path), and
the session assembler assembles from the captured definition instead
of reselecting from mutable registry state. Disabling or editing a
definition after preparation can no longer change an accepted launch.

Tests: LaunchPreparer selection/copy tests, service-door rejection
tests proving no manager record is created for unknown or disabled
ids, an assembler test proving the captured definition wins over later
registry state, and conversion of both door suites onto the shared
seam. 2,280 tests passing.
