# Triage labels

| Canonical role | GitHub label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Maintainer evaluation |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Translate skill role names through this table.

During triage, use exactly one state label and one category label:
`bug` or `enhancement`. Flag conflicting states before changing them.
Setup does not relabel existing issues.
